## Цель: провести диагностику монитора и выбрать оптимальные параметры цветового отображения

## Теоретические сведения: 
MonitorTest — утилита от разработчиков «PassMark Software», которая позволяет производить различные тестирования монитора.

Возможности программы:
•	Поддержка для всех доступных разрешений и глубины цвета.
•	Контрастность.
•	Анализ цветопередачи.
•	Шрифты.
•	Поддержка большинства типов мониторов.
•	Тест экранов Multitouch 
•	Конвергенция 
•	Поддержка более 300 режимов работы видеокарт.

### Тест Contrast (насыщенность цвета)

> ⚙️ **Оптимальный шаг различимости цвета – 20%**

| Цвет | Процент насыщенности | Вывод |
|------|---------------------|-------|
| 🔴 **Red** | `20%` | Градации красного становятся отчётливо различимыми при шаге 20%. При уменьшении интервала до 10% тёмные тона визуально объединяются |
| 🟢 **Green** | `20%` | Зелёный спектр показывает наилучшую детализацию: полутона различимы уже в диапазоне 15–20% |
| 🔵 **Blue** | `25%` | Для синего канала необходим увеличенный интервал (25%), чтобы обеспечить уверенное визуальное разделение оттенков |
| ⚪ **White** | `20%` | Оттенки серого воспроизводятся корректно, шаг 20% гарантирует плавную градацию без видимых скачков |

> **📌 Общий вывод по контрастности:**  
> Дисплей демонстрирует стабильную передачу близких тонов. Базовый порог различимости для основной цветовой гаммы — **20%**, что укладывается в рекомендуемые нормы. Для синего субпикселя целесообразно повысить контрастность на **+5–10%**, чтобы улучшить проработку деталей в теневых участках.  
> **Рекомендуемые настройки контрастности:** `70–80% от максимума`

## Контрольные вопросы:

#### 1. Виды мониторов

| Тип | Принцип работы | Особенности |
|-----|---------------|-------------|
| **ЭЛТ (CRT)** | Электронно-лучевая трубка, люминофор | Устарели, большие габариты, мерцание |
| **ЖК / LCD** | Жидкие кристаллы + подсветка | Тонкие, энергоэффективные, доминируют на рынке |
| **• TN** | Скручивание кристаллов | Быстрый отклик, но узкие углы обзора и слабая цветопередача |
| **• IPS** | Параллельное выравнивание кристаллов | Отличная цветопередача, широкие углы обзора, выше цена |
| **• VA** | Вертикальное выравнивание | Высокая контрастность, глубокий чёрный, средний отклик |
| **OLED** | Самоподсвечивающиеся органические диоды | Идеальный чёрный, высокая контрастность, риск выгорания |
| **Mini-LED** | LCD с множеством зон локальной подсветки | Улучшенная контрастность, яркость, без риска выгорания OLED |

#### 2. Конструкция ЖК-мониторов (слои «сэндвича»)

```
┌─────────────────────────┐
│ 1. Защитное стекло       │ → Защита матрицы, антибликовое покрытие
├─────────────────────────┤
│ 2. Поляризационная плёнка│ → Фильтрация света по направлению
├─────────────────────────┤
│ 3. Цветовой фильтр (RGB) │ → Формирование цвета субпикселей
├─────────────────────────┤
│ 4. Жидкие кристаллы      │ → Управление прохождением света (пиксели)
├─────────────────────────┤
│ 5. TFT-матрица           │ → Транзисторы управления каждым пикселем
├─────────────────────────┤
│ 6. Подсветка (LED)       │ → Источник света (Edge-LED или Full-Array)
├─────────────────────────┤
│ 7. Задняя панель/корпус  │ → Электроника, крепления, охлаждение
└─────────────────────────┘
```

**Ключевые компоненты:**
- **TFT-контроллер** — управляет напряжением на каждом пикселе
- **Инвертор/драйвер подсветки** — регулирует яркость LED-массива
- **Scaler (видеопроцессор)** — преобразует входной сигнал в разрешение матрицы
- **Плата управления (AD-board)** — обработка сигналов, меню, настройки

> 💡 **Принцип работы:** Подсветка создаёт равномерный свет → жидкие кристаллы под напряжением меняют ориентацию, пропуская или блокируя свет → цветовой фильтр формирует RGB-компоненты → на экране формируется изображение.
